# RocketLab 2026.2

Projeto solo em um único repositório. Backend e frontend pertencem à mesma entrega; trabalhe na `main` atual. O enunciado está em `Atividade de Dev.pdf`.

## Agent skills

Use como conjunto padrão das skills de Matt Pocock: `domain-modeling` para decisões do domínio, `tdd` para os comportamentos essenciais e `code-review` para conferir a entrega contra o enunciado. Acione as demais skills de Matt somente quando o usuário pedir ou surgir sua condição específica. Se outra skill ou plugin sugerir TDD ou revisão equivalente, prefira este fluxo e faça cada etapa uma vez.

### Issue tracker

O trabalho corrente é acompanhado no próprio repositório. Se uma especificação ou tarefa precisar ser registrada, use Markdown local em `.scratch/`. Veja `docs/agents/issue-tracker.md`.

### Domain docs

Use um único contexto para este repositório. Leia `CONTEXT.md` e os ADRs pertinentes quando existirem; crie-os apenas quando uma decisão justificar. Veja `docs/agents/domain.md`.
