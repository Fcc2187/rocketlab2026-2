# Issue tracker local

Este projeto solo é desenvolvido e versionado na `main`. Não há rastreador externo configurado.

Se uma skill exigir uma spec ou um ticket, registre em `.scratch/<funcionalidade>/`: `spec.md` para a especificação e `issues/NN-<nome>.md` para cada ticket, numerado a partir de `01`. Registre dependências entre tickets em uma linha `Blocked by:`. Leia o arquivo indicado quando a skill pedir o ticket correspondente.

Crie esses arquivos somente quando forem úteis para trabalho que ultrapasse uma sessão. Para tarefas pequenas, use o enunciado e o código diretamente.
